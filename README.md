# CineData Analytics

Pipeline de dados desenvolvido em Databricks utilizando arquitetura Medalhão:

- Landing → Bronze
- Bronze → Silver
- Silver → Gold

## Arquivos

- `Landing_to_Bronze.ipynb`
- `Bronze_to_Silver.ipynb`
- `Silver_to_Gold.ipynb`
- `job.yaml`
- `job_execution.png`

O pipeline utiliza tabelas Delta, PySpark e Databricks Workflows.
